### Baseline CI failure

`flow_action_history_budget_preserves_known_success_and_failure` failed the
serialized Flow steps size assertion (`<= 4,194,304` bytes) in the baseline
Rust test job. CommandBus reported 214 passing and one failing test. A
previous parallel run recorded the same assertion failure and passed the
isolated rerun. This preparation's Windows isolated rerun also passed (1/1)
using `cargo test --locked --offline -p unfour-command-bus --features ssh-native --lib flow_action_history_budget_preserves_known_success_and_failure -- --nocapture`.

The runner journaled expanded arguments before dispatch and checked the history
budget only after the executor returned. A deadline could bypass that check.
The fix omits oversized arguments before writing the attempt while retaining
them for execution. The regression uses a SQLite trigger to reject oversized
in-flight history and checks the final history size, credential redaction, and
confirmed success and failure outcomes. The Windows run of
`cargo test --locked --offline --workspace --exclude unfour-mcp --no-fail-fast`
passed, including all 215 CommandBus tests and all 8 Flow engine tests.

### Small terminal-curl requests

The fast transfer requires a successful curl capability check that verifies
exact input and restoration in the same live shell. The shell context is
revalidated before attempting the fast transfer path. Required curl options
are checked for every send. The config must fit the tested 720-byte sample and
the encoded frame limit. SHA-256 verifies the upload.
Missing or invalidated qualification, a narrow relay, an oversized frame
or a body that begins with `@` uses the conservative path when compatible.
Both paths keep manual input isolated until restoration is confirmed.

In the prior Windows x64 test using Git for Windows POSIX PTY, curl 8.18.0
and a local HTTP fixture with 200 ms server delay, a 130-byte JSON body under
**680 ms injected RTT** reached terminal restoration in a median 10.063 s
on the previous conservative implementation, 6.734 s with the new
conservative transfer and 5.078 s with the qualified fast transfer
(three samples each). At zero injected RTT the measured fast path was
slower than the baseline. Actual customer latency, HTTPS and relay capacity
remain **NOT VERIFIED**. [Measurement method and results](bastion-curl-latency-2026-11-18.md)

## Standard RC E2E repair

Follow-up recorded on 2026-11-19 (Asia/Shanghai). The candidate on
`e28cb6e87c45c9ae4a9f88bd3558e292e786190f` passed identity, lint, frontend
tests, release contract, compile checks and Rust tests. Chromium E2E failed
with 78 passing and 6 failing. The signed installer build matrix was skipped.
The local `main` worktree was clean at that SHA before the repair.
[Failed Standard Release Candidate](https://github.com/zyqzyq/Unfour/actions/runs/44471166566)

- **Browser mock snapshots.** Environment activation mutated records already
  in the React Query cache. Structural sharing kept the original array, so
  API Send used a stale environment ID and the pre-send route check rejected
  it before HTTP. `mockInvoke` now clones handled results at the return
  boundary, including results from async handlers. The environment ID and
  effective route checks remain in place. Unit coverage checks old snapshots
  and nested variables. Browser coverage checks the HTTP URLs before and
  after activation, including the existing race cases.
- **SSH focus.** A Chromium `focusin` and `HTMLElement.focus()` trace showed
  that switching from Tasks to Connections queued both the activation and
  re-fit animation-frame callbacks. With those callbacks held until manual
  sidebar collapse, each independently moved focus from `Expand sidebar`
  to the xterm input. Re-fitting, PTY size sync and repaint now run without
  focusing the terminal. Activation and explicit session-tab selection can
  still focus it, with pending focus yielding to a later focus, pointer or
  keyboard interaction. The browser regression still checks the sidebar
  button and the full command-history completion sequence.
- **Workbench surfaces.** The light and dark tests now check title, activity
  and status chrome, the resource sidebar surface and the workspace canvas by
  region. The editor, data, contrast and live-theme checks exercise the
  existing palette and layout.
