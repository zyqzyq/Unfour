# C2 UI adoption — November 8, 2026

The user selected C2 for the completed desktop workbench redesign and authorized
committing the experiment branch and merging it into local `main`. No push or
release is included. Baseline: `36a75353`.

## Adopted result

- The redesigned shell and API, Database, SSH/SFTP/tasks, Flow, and Settings
  surfaces retain their accepted layout, typography, spacing, icons, and behavior.
- C2 is the default shared palette. Light mode uses neutral surfaces with
  `primary #6e40bd`, `primary-hover #5d32a8`, `primary-soft #eee7fa`, and
  `focus #7640cd`. Dark mode retains the C neutral/periwinkle palette.
- All 63 experiment color tokens per mode match the adopted defaults. API and
  SQL Monaco themes use the same colors and register both modes for live switching.
- Temporary palette URL parsing and CSS variants are removed from the runtime.
  Existing light/dark/system settings and persistence remain unchanged.
- Packaged U application icons are unchanged: 51 tracked icon assets were
  compared with the baseline. No backend, business data, dependencies, or
  execution/confirmation logic changed.
- Current rules are in [design-system.md](../ui/design-system.md). Original
  comparison screenshots/viewers remain historical evidence. Experiment code is
  preserved as text in the [source archive](artifacts/color-accent-2026-11-08/source-archive/).
  Local `baseline/` recovery backups remain on disk and are excluded from Git.

The first broader browser run reported 43 passes and 9 failures. Several failures
explicitly recorded a document reload in the middle of an interaction, resetting
the active module or dialog. This failed run is retained in the evidence rather
than counted as passing. After file edits stopped, the complete 56-test suite
passed with four workers and zero retries, including every earlier failure.
No product changes or weakened assertions were used to obtain that result.

Build output retains the pre-existing Vite warning about chunks exceeding 500 kB.
ESLint warnings concern existing large functions in SQL editor, table grid, SSH
connection tree, and terminal pane; this visual change does not refactor them.

Browser tests use the real React UI with isolated browser adapters and deterministic
fixtures. They do not establish native Tauri behavior or real HTTP, database-engine,
SSH, and Flow execution. Those integrations and high-DPI native rendering are
**NOT VERIFIED** in this frontend-only adoption step.
