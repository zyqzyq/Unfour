## 本轮现场证据

上一版 Task 在同一 SSH 传输上新开 exec 通道，没有继承父终端内的交互登录。
现场运行 `printf 'TASK_BEGIN\n'; ls; ...; exit ...` 后只收到终端标题控制序列和
`login:`，约 15 秒结束为结果未知。没有 BEGIN/END 或退出码，不能记为目标命令成功。
固定 exec 检测未验证目标资产身份；它通过也不证明新通道已进入终端中的目标机。

## 使用步骤

1. 关闭旧版 Unfour，备份并替换主程序，再通过原有堡垒机入口重新启动。
2. 在临时终端完成登录和目标资产选择，手工确认当前机器及目录，停在空闲 shell
   提示符。本轮终端模式适用于具备 `sh`、`stty`、`cat` 的 POSIX shell；登录框、资产菜单、
   数据库交互程序、编辑器及正在运行的前台程序都不是可执行状态。
3. 在能力检测中选择“已登录终端”对应项目，确认当前终端空闲后检测。它在当前终端
   测试命令和退出码，不再另开 exec 通道。通过后终端应恢复手工输入。
4. 创建只含 command 的 SSH Task，名称正常填写，默认连接可留空。先用只读命令
   `printf 'TASK_BEGIN\n'; ls; printf 'TASK_END\n'`，超时设为 20 秒。
5. 运行时选择当前临时节点及“复用已登录终端”模式，确认终端已进入目标机器且空闲。
   应看到开始/目录/结束输出及成功状态。运行期间终端输入被占用；结束后可手工执行
   `printf 'TERMINAL_READY\n'` 检查父终端仍可用。
6. 用单独的 command 步骤 `exit 23` 检查失败退出码。Task 应失败，但父终端不退出。
   后续步骤不得继续执行。工作目录配置只作用于任务子 shell。
7. 在获准的测试会话执行 `sleep 20` 并取消。取消不等于已确认远端进程停止；若无法
   确认终端恢复，界面应要求重新连接，不能自动重试任务或把它记为成功。
8. 复查原生 exec 模式的现场 `login:` 情形：应及时显示登录提示诊断，无可信退出码
   时仍保留结果未知。不要在 Task 输出框提供账号或密码。

仅记录脱敏能力报告、成功/失败及固定错误码。不要带回票据、原始启动参数、用户输入
或客户目录内容。保留原先 API TCP 转发的独立检测流程；本轮不会绕过堡垒机转发策略。

## 模式边界

- 终端模式显式启用，没有原生 exec 失败后自动改用终端的行为。
- 复用当前交互终端，仅支持 command；upload/download 仍需原生 SFTP 能力，不能把
  终端模式检测通过当作文件传输支持。临时目标 Flow 尚未实现。
- 输出经同一个 PTY 返回，stdout/stderr 合流。任务在非交互子 shell 中执行，不继承
  父 shell 未导出的变量、别名或函数；命令 stdin 不用于交互输入。
- 固定且无敏感值的引导行可能被远端 shell 历史记录；任务正文在关闭回显后的协议
  子进程中传递。不能声称客户主机、堡垒机审计或远端程序绝不记录任务内容。
- 任务目标、运行参数及结果仍仅在本机内存保留；关闭临时会话或应用后不恢复运行。
- 能力通过仅描述当次会话的测试结果；目标身份需要使用者在终端确认。
