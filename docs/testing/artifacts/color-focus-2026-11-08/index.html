C 的中性背景，配上紫色焦点

C+（C＋紫色焦点）只将浅色 --u-color-focus 从 C 的 #4452b4 换为 B 的 #7640cd。紫色提示沿用现有令牌消费者，包含焦点边框、当前编辑位置、编辑器光标及分割线悬停等小面积提示。默认比较 C 与 C+ 的真实局部截图，也可加入 B 作为参照。

仅浅色焦点令牌改变 背景、文字、主按钮、选中底色、语法色与状态色完全沿用 C。 深色仍是 C，未创建新的深色方案。
