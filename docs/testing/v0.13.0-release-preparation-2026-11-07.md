### Failed attempts and environment limits

- **FAIL (environment):** pnpm launcher attempts could not create its managed
  package-manager symlink in the Windows sandbox. Build was rerun through the
  installed Node entrypoints without installing or changing dependencies:
  `node scripts/prepare-monaco.mjs`,
  `node node_modules/typescript/bin/tsc -p apps/desktop/tsconfig.json`, and
  `node node_modules/vite/bin/vite.js build apps/desktop`.
- **FAIL (environment):** the initial Vitest run failed to rename temporary SSR
  cache files (`EPERM`); all 215 suites failed before executing tests. The same
  suite passed outside the sandbox. No assertion or test configuration was weakened.
- **FAIL (environment):** the first browser run could not start its configured
  server because the temporary Vite process occupied port 1420. That process was
  stopped; the rerun let Playwright own its server and all 48 tests passed.

The Rust workspace suite includes three local-data-clock tests, a real stdio
MCP consistency test using temporary SQLite stores, and a binary stdio protocol
contract test. The persistence tests establish
cross-process persistence and backend reads, not native WebView delivery. The
ignored OS-keychain smoke requires separate explicit credential-store acceptance.
