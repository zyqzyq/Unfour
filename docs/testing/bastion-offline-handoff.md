## 现场记录模板

记录 Unfour commit/package SHA-256、AccessClient 版本与 LoaderShell SHA-256、
可取得的服务器版本、日期和测试环境别名。每一行独立填 `PASS` / `FAIL` /
`UNSUPPORTED` / `NOT RUN` / `INCONCLUSIVE`，附脱敏依据与最小缺失条件。
`UNSUPPORTED` 必须有明确拒绝或已知产品边界，不能替代未知。

| 场景 | 当前状态 | 所需结果 |
| --- | --- | --- |
| 冷启动、已有实例、UI 未就绪、连续重复启动 | NOT RUN | 正确且各消费一次；记录末端进程退出对代理的影响 |
| 工作区选择/切换/关闭、标签关闭、取消、超时 | NOT RUN | 归属不变、资源清理、无恢复记录/自动重连 |
| 未知/变更主机指纹 | NOT RUN | 指纹检查与约定的临时首次信任策略生效；变更不能自动放行 |
| 终端两条顺序无害命令 | NOT RUN | 仅在一次性目标手工执行，例如 `printf 'fixture-one\n'` 与 `printf 'fixture-two\n'` |
| 终端成功/非零结果 | NOT RUN | 可用隔离子 shell `(exit 0); printf '%s\n' "$?"` 和 `(exit 7); printf '%s\n' "$?"`；不证明 native exec |
| 原生 exec 与可靠 exit-status | NOT RUN | 需独立批准的测试工具/入口与通道；本阶段不新增 Task/Flow 来完成它。无法执行则保留未验证 |
| 第二次登录 | NOT RUN | 区分新授权与同一材料复用，不默认可重用 |
| 并发通道与顺序通道复用 | NOT RUN | 分别授权并记录限制是并发数还是连接生存期总数 |
| WinSCP/SFTP 入口、认证、一次上传与摘要 | NOT RUN | 独立授权；上传合成文件，核对摘要并清理 |
| 到期、代理退出、受控断线 | NOT RUN | 仅一次性会话；记录终态、清理与重新从网页发起的行为 |

额外登录/通道测试不能在客户工作会话中自动探测；不重复连接“试一下”。
执行结果丢失时记 `INCONCLUSIVE`，不要推断远端成功或可安全重试。
将脱敏结果更新到 A4 和总任务 #3；#3 继续保持开放，不由阶段一终端成功关闭。
