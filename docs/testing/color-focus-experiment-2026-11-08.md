## 临时切换

- B：`?palette=B`
- C：`?palette=C`
- C+：`?palette=C&focus=violet`

在现有开发地址后使用对应查询参数并刷新；请先保存正在编辑的内容。
通过原设置选择浅色。深色 C+ 与原 C 完全相同，继续沿用已有主题持久化。
查询参数不写入存储，也没有增加正式主题管理入口。

## 比较条件与证据

使用真实 React 工作台和同一套隔离浏览器测试数据，固定 1440×900、1× 像素比例。
API 点击 Send 显示相同 200 响应，URL 保持焦点；Database 在 Monaco 编辑后点击 Run All，
显示相同五行数据并选中相同单元格。局部图直接从运行页面截图裁切。
这些截图用于比较前端配色，不验证真实数据库、SSH 或原生 Tauri 执行。

不透明焦点色对 9 个常用表面的最低对比度：C 浅色 4.72:1，C+ 浅色 4.34:1，
均高于本次非文字焦点色检查的 3:1；深色保持 4.99:1。
此项只计算原始颜色配对，不代表对所有透明焦点环的完整无障碍认证。
