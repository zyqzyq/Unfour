# Unfour v0.11.0

> Draft for the future GitHub Release. v0.11.0 is not released; replace this
> draft notice only after candidate acceptance and publication authorization.

Unfour v0.11.0 makes it easier to move a complete developer Workspace between
devices and keep a password-protected local backup, with safer authentication,
credential editing, and startup behavior.

## Move a whole Workspace

Export variables, environments, API definitions, SSH/Database connection settings,
SSH tasks, Saved SQL, and local Flow definitions together. Review an import before
creating a new, independent Workspace, with references remapped to the new copy.
Sharing exports remove recognized secrets and omit device paths by default.

## Keep an encrypted local backup

Choose **Encrypted backup** to protect the export file with a password. Optionally
include saved connection passwords, SSH key passphrases, secret variables, and API
authentication values. Restore supported credentials locally and review or replace
device paths before using the imported connections and tasks.

Keep the backup password separately: it cannot be recovered. Backups do not embed
private-key files, database files, or upload/download file contents, and do not
include histories, layouts, host trust, or Cloud Sync bindings. Literal secrets in
bodies, scripts, SQL, and Flow defaults remain subject to redaction; inspect
free-form content before sharing any definitions export.

**Encrypted backups are local files, separate from Pro Cloud Sync. This release
does not support sensitive-data Cloud Sync.** Flow definitions and run history
remain local-only. Restoring a backup does not add at-rest encryption to SQLite.

## Fixes that make daily work safer

- Keep API edits made while Send or save is pending. Resolve variables before
  Basic/Bearer/API Key authentication and preserve explicit Header/Query overrides.
- Improve runtime credential redaction in history and diagnostics. OpenAPI export
  handles invalid Auth per request and omits historical response examples when
  their credential provenance cannot be established safely, including after
  credential rotation. Ordinary public examples remain available.
- Separate showing a saved secret from replacing or clearing it. Protect shared
  connection credentials, recover interrupted staging, and avoid holding SQLite
  locks while reading a credential for display.
- Restore the Database sidebar's Design Table action and browse table pages
  without waiting for a full row count, with accurate next-page and row-range UI.
- Preserve ephemeral MCP/Flow storage through cancellation and finish history
  repair rollback before later startup writes.
- Keep sensitive variable values out of Cloud Sync even when their Secret flag
  was unset; quarantine unsafe older retries while repairing safe local intent.

History repair can redact recognized fields whose source values remain available;
it cannot reconstruct credentials already replaced by markers or guarantee complete
erasure of every legacy response echo. OpenAPI export applies a conservative
response-example policy without rewriting saved requests or history.

## Installation

The candidate follows the existing distribution policy: Windows x64 NSIS,
macOS Apple Silicon/Intel DMG, and experimental Linux x64 AppImage. Windows
installers remain unsigned; macOS builds remain unsigned and unnotarized, so OS
trust warnings may appear. Tauri updater signatures are separate from OS code
signing. Microsoft Store packaging remains a separate manual process.

For a published Standard release, verify downloaded installers with its
`SHA256SUMS.txt`. Install macOS using the DMG; `.app.tar.gz` is reserved for the
internal updater. See the [Workspace backup guide](../user/USER_GUIDE.md#workspace-exchange-and-local-backups)
for import, restore, and sharing limits.
